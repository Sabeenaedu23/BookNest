# BookNest – Online Bookstore

BookNest is a responsive online bookstore developed using HTML, CSS and JavaScript. The application provides an interactive interface for browsing books, searching by title or author, filtering categories and managing a shopping cart and wishlist.

## Features

- Responsive design for desktop, tablet and mobile devices.
- Book listings with titles, authors, categories and prices.
- Search functionality for books and authors.
- Category-based filtering.
- Sorting by price and book name.
- Shopping cart with quantity management.
- Wishlist functionality.
- Book preview with descriptions and pricing.
- Local Storage for saving cart and wishlist data.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
